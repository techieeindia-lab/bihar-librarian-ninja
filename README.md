# Bihar Librarian Ninja (बिहार लाइब्रेरियन निंजा)

A dedicated, bilingual (Hindi & English) mobile & web learning app tailored for aspirants preparing for the **Bihar School Librarian Examination** and other Library & Information Science (LIS) competitive exams.

## 🚀 Key Features

- **7-Unit Comprehensive LIS Syllabus**: Detailed notes, key milestones, classification schemes (DDC, CC), reference sources, and Bihar GK.
- **Interactive Flashcards**: Quick flip-cards for rapid memory retention of key years, founders, and concepts.
- **Mock Tests & Sectional Tests**: Timed quizzes, bilingual questions with in-depth explanations, instant scoring, and performance analytics.
- **Offline Bookmarks & Revision**: Save tricky questions for quick review.
- **Daily Streak & Stats**: Track active study days, accuracy rate, and total practice questions completed.
- **Light & Dark Mode**: Handcrafted sleek design system with full theme toggling.
- **Bilingual Switcher**: Seamless 1-tap toggle between Hindi and English across all screens.

## 🛠 Tech Stack

- **Framework**: [Expo SDK 57](https://expo.dev) + React Native
- **Language**: TypeScript
- **State & Local Storage**: `@react-native-async-storage/async-storage`
- **Navigation & Icons**: `@expo/vector-icons` (Ionicons)
- **Web Support**: `react-native-web`, `@expo/metro-runtime`

## 🏃 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Running Locally
```bash
# Start Expo development server
npm start

# Run on Web in browser
npm run web

# Run on Android emulator / device
npm run android
```
